# projet_fictif_pour_donner_un_example
## Introduction
Juste un projet fictif. On peut mettre du texte en **gras**. On peut aussi mettre du texte en _italique_.

On peut faire des listes:
 * comme un item
 * comme deux items

On peut aussi faire d'autres listes: 
 - un item
 - un autre item

En fait on peut faire plein de listes.
 - [ ] un item
 - [ ] un autre item
